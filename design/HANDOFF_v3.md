### 1-2. 새로 넣을 토큰 묶음
값은 `tokens.css` 맨 아래에 주간(`:root`) · 야간 두 벌로 있다. 이름은 CSS에서 `--color-` 뒤를 camelCase로 바꾸면 된다(예: `--color-selection-background` → `selectionBackground`).

| 묶음 | 쓰는 곳 | 핵심 값(주간 / 야간) |
|---|---|---|
| `selection-*` | 고른 목적지 카드 · 쉰 시간 칩 · 제안 항목 · 설정 방식 · 방금 기록 꼬리표 | 면 #D9F77A / #D9F77A, 글자 #242033 / #242033, 테두리 #242033(주간 2px) / #D9F77A |

| `switch-*` | 설정 스위치 | 켜짐 트랙 #D9F77A / #CDEA6D, 손잡이 #242033 |
| `field-*` · `focus-ring` | 검색 창 | 커서 · 포커스 #242033 / #D9F77A |
| `receipt-*` | 영수증 종이 · 출력구 · 합계 마커 | 종이 #FFFFFF / #312C40, 마커 #D9F77A / #445616 |
| `status-*` | 인터넷 없음 · 실패 · 안내 | 경고 · 오류 · 안내 면 + 글자 짝 |
| `illust-*` | 노고 카(5-4) · 홈 로고 바닥 그림자 | 33개. 차체 · 유리 · 휠 · 그림자 |

| `notification-dot`(v93 새로) | 알림 종 빨간 점 · 알림 창 새 알림 점 | #E5484D / #FF6B6B |
| `button-destructive-*` | 그만두기 · 기록 초기화 확인 | #9D303D / #FFADAD |

### 10-3. 새 디자인 규칙 (디자인 시스템에 추가, 앱에도 같은 규칙)

① **한글 줄바꿈 `cg-kwrap`**(D3 · 디자인 시스템 › 글꼴)
- 어절(띄어쓰기 단위) 안에서는 끊지 않는다(`word-break: keep-all`).
- 두 줄 이상이면 줄 길이를 고르게(`text-wrap: balance`): "남양주 물의정원 / 북한강 산책로", "한화리조트 대천 / 파로스 오션타워".
- 한 어절이 한 줄보다 길 때만 어절 안에서 끊는다(`overflow-wrap: break-word`).
- 쓰는 곳: 두 줄까지 쓰는 이름(출발 목적지 카드). 넘치면 둘째 줄 끝 "…".
- Compose: `TextStyle(lineBreak = LineBreak.Heading)` 계열(줄 균형) + 어절 단위 끊기. 기기에서 어절 단위가 안 되면 어절 안 글자 사이에 U+2060(단어 결합)을 넣어 같은 결과를 낸다. **기기(Pleos AAOS) 지원 범위 확인 부탁**.
- 시험: 장소 이름 50개 × 가로 · 분할에서 어절 쪼개짐 44건 → 0건(`hD-design/한글줄바꿈_테스트_1112.md`, 웹 시안 기준). 가로 창에서 세 줄이 되는 이름 3건은 둘째 줄 끝 "…".

② **큰 숫자 길이 `cg-big.cg-sm`**(D4)
- 기본: "한 사람 약 ○" 가로 Headline L(800 60/80) · 분할 Headline S(800 48/64).
- 표시 금액이 **10만 원 이상**("약 ○○만 …")이거나 큰 숫자 줄이 **15자 이상**(띄어쓰기 포함)이면 한 단계 작게: 가로 Headline M(800 56/72) · 분할 Title L(700 40/52).
- 줄바꿈 · 말줄임 없이 한 줄. 쓰는 곳: 도착 제안 카드(방식 A) · 중간 정산 큰 숫자.
- 판정(시안 코드): `/\d{2,}만/.test(text) || text.length >= 15`.

③ **문장 속 장소 이름 말줄임 `cg-pnl > cg-pn + cg-pr`**(D2)
- 장소 이름(`cg-pn`)만 줄이고 뒤 문구(`cg-pr`: "으로 가는 중 · 14:20 출발 · 함께 4명", "에 도착했어요", " 기록을 남겼어요")와 버튼은 늘 보이게.
- 쓰는 곳: 홈 가는 중 작은 줄 · 도착 대기 작은 줄 · 계산 연출 · 도착 · 정리하지 못함 머리 · 알림 창 줄.
- 브라우저 기본 말줄임은 "…" 뒤에 글자 하나쯤 빈칸이 남는다(v121에서 고침). 시안은 넘칠 때만 글자 수를 줄여 "…"를 직접 붙이고 이름 칸을 내용 폭에 맞춘다(JS `fitPN`). 정적 화면 파일(`screens/*.html`)에는 JS가 없어 CSS 말줄임으로만 보인다 → 모양은 `prototype/index.html`로 확인.
- Compose: `Row { Text(이름, maxLines = 1, overflow = TextOverflow.Ellipsis, modifier = Modifier.weight(1f, fill = false)); Text(뒤 문구, softWrap = false) }`. "…" 뒤 빈칸이 생기면 `TextMeasurer`로 들어가는 글자 수를 재서 "…"를 직접 붙인다.

④ **"+1% 미만" 작은 글자 `cg-pc.cg-lt`**(D5 · S2)
- 1%가 안 되는 줄(예: 2시간 10분 중 밤길 10분)은 "+1% 미만"을 가로 Label M · 분할 Label S로. 다른 줄과 % 칸 폭은 그대로(가로 130 · 분할 84).
- 영수증 · 기록 상세 · 중간 정산 영수증 공통. 계산 연출 원 아래 값에도 "+1% 미만".

⑤ **시간 표기 "○시간 ○분"**(S1)
- 영수증 값("+1시간 15분", "2시간 넘긴 11시간 10분") · 계산 연출 원 아래 값 · 꼬리표 모두 같은 함수. 0분은 아직 "0분"(S3 미정).

⑥ **쉰 시간은 늘 묻는다**(S4 · S5)
- 모든 주행(짧은 주행 · 맑은 길 포함)과 **중간 정산**에서 도착과 같은 짧은 하단 시트("중간에 쉰 시간이 있었나요?" · 없음 · 15분 · 30분 · 1시간 이상).
- 고르기 전: 영수증 자리 "오늘(지금까지) 운전을 정리하는 중이에요", 제안 자리 "확인 중".
- 영수증의 "중간에 쉰 시간" 값을 누르면 시트가 다시 뜬다(바꾸기 버튼 없음).
- 중간 정산에서 고른 값은 최종 도착 영수증의 "중간 정산 몫"(전체 − 중간 정산 포함 모드) 계산에도 쓴다.
